# Reef Explorer — Project Notes

## Problem, concept and objectives

New divers need a short, guided underwater survey practice. This experience teaches movement, grabbing, tool use and data logging in about 5–7 minutes.

Measurable objectives for a complete dive:

1. Choose control mode (VR / Desktop).
2. Finish short tutorials (move, grab, activate).
3. Collect scanner and sample bottle.
4. Visit three reef zones.
5. Scan clownfish, sea turtle and ray once each.
6. Fill the bottle at the sampling point.
7. Return the filled bottle to the station holder.
8. Submit the dive log and view simulated comparison results.

## Why VR suits this experience

VR supports presence through natural pointing, grabbing and looking around a 3D reef. Scale and depth are easier to understand than on a flat map. Desktop mode is included so the mission remains completable without a headset.

## Locomotion and tracking origin

- Default locomotion: teleportation + snap turning (from XR Interaction Toolkit Starter Assets).
- Tracking origin: Starter Assets XR Origin default (`Requested Tracking Origin Mode = Not Specified` / device default), intended for seated or standing play at a desk or clear play space.
- Comfort: avoid continuous locomotion by default; keep camera motion gentle; fog and particles are kept modest.

These choices were made for comfort design, not validated on a physical headset in this environment.

## Immersion / presence / D.I.C.E. (simple notes)

- **Sensory**: blue-green underwater lighting, fog, soft particles, spatial station hum, scanner tones.
- **Challenge**: find animals, aim scanner, fill and return bottle.
- **Narrative**: research diver updating a missing survey.
- **Social**: single-player coursework experience (group development, not multiplayer).

## Architecture

- `MissionController`: state machine and progress.
- Interaction scripts: scanner, bottle, zones, sockets, respawn.
- Survey module: ScriptableObject species/baseline, analyzer, JSON saver.
- Input: XR Origin and Desktop player are mutually exclusive.
- UI: world-space mission board + HUD + pause menu.
- Editor menus generate the scene safely and can be re-run.

## Advanced feature — simulated survey analysis

Observations are compared with baseline ScriptableObject data by species and zone. Results show counts, differences, coverage and missing items, with clear educational disclaimers. Completed logs save as JSON under `Application.persistentDataPath/DiveLogs`.

## Asset and audio credits

- Unity URP template materials/primitives.
- XR Interaction Toolkit Starter Assets, XR Device Simulator, XR Interaction Simulator (Unity package samples).
- Procedural WAV tones/noise generated by `Reef Explorer/2. Build / Refresh ReefExplorer Scene` (no third-party audio downloads).

No paid store assets were required for the generated stylized environment.

## AI assistance disclosure

AI coding assistance (Cursor) helped scaffold scripts, editor setup tools, survey analysis code, documentation and project organisation. Students must still run Unity menus, playtest, adjust balances and defend design decisions themselves.

## Known limitations

- Grab verification in this automated session is code/setup based; Play Mode grab must be confirmed in Unity.
- Headset comfort/presence/performance not validated here.
- Animals use simple primitives with wander motion.
- Procedural audio is functional, not production-quality scoring.
- Windows standalone build may still need a local build step after scene generation.
